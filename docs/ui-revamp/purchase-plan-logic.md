# Purchase plan logic

| Plan | Whose move | Tab | Card button |
|---|---|---|---|
| Draft | You | To do | View recommendation + Edit |
| Overdue draft | You | To do | Edit |
| Approved | You: buy and record it | To do | Record purchase → |
| Submitted | Manager | Awaiting approval | View submitted recommendation |
| Rejected | Nobody has to act | Finished | Copy to new draft + View decision |
| Rejected, already copied | Nobody has to act | Finished | View copied plan → + View decision |
| Purchased | Nobody, it's done | Finished | View purchase record |
